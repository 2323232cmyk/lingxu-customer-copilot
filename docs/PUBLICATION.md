# 公开副本与脱敏范围

此仓库从桌面应用 0.11.5 的当前源码建立，全新 Git 历史，不包含内部开发历史或分支。

## 已移除或替换

- 不包含 Android/LSPosed 模块、其他应用安装包、反编译产物或第三方闭源 DLL。
- 不包含客户资料、聊天/录音、数据库、账号配置、环境文件、登录态、凭据、签名或服务器部署文件。
- 不包含内部知识库、工程记忆、工作交接、运行诊断、设备信息和历史安装程序。
- 公司知识、CRM 和更新服务地址替换为保留示例域名；公司人员名和本机标识改为示例内容。
- 演示负责人和资料为虚构。测试里的固定号码、证件格式及伪令牌是合成边界样本，不是可用账号或从客户系统导出的数据。
- 公开版使用独立用户目录与安装名称，默认本地知识库、关闭自动更新，避免读取内部安装的配置或连接内部服务。

## 保留

桌面界面与逻辑、类型、合成测试、构建脚本、依赖锁、品牌素材及必须的第三方声明。兼容性、能力和平台风险按实际证据说明，不增加未验收的自动发送或视频号功能。

## 后续更新

只在本公开仓库中提交已经审查的变更。不要直接 merge 内部仓库历史、使用镜像推送或从开发目录整仓复制。任何新增样例、截图、日志与附件都须重新审查；只在合成数据模式生成可公开截图。

发布前应通过敏感内容扫描、Git 历史扫描、类型检查、lint、合成测试和生产源构建。扫描是辅助检查，不代表任何未来提交自动安全。
